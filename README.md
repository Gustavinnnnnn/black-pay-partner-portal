# Black Pay Partner Portal

BLACK PAY — FORMULÁRIO OFICIAL DE CANDIDATURA



Quero desenvolver uma página completa e profissional de recrutamento e seleção para a BLACK PAY, uma gateway de pagamentos que já está em funcionamento.



O objetivo é criar um formulário para receber candidaturas de pessoas interessadas em entrar na operação da Black Pay em três modalidades diferentes:



1. Suporte.

2. Sócio investidor.

3. Sócio de divulgação e expansão.



A página precisa transmitir profissionalismo, exclusividade, confiança e oportunidade de crescimento empresarial.



Não quero um formulário genérico. Quero uma experiência visual premium, personalizada para a identidade da Black Pay.



---



1. IDENTIDADE VISUAL



Utilizar exclusivamente a identidade visual da Black Pay:



- Preto como cor predominante.

- Vermelho como cor de destaque.

- Branco para textos e informações.

- Cinza escuro para superfícies secundárias.



Direção visual:



- Aparência premium e moderna.

- Fundo predominantemente preto.

- Detalhes vermelhos discretos.

- Gradientes vermelhos muito sutis.

- Cards escuros com bordas elegantes.

- Cantos arredondados.

- Microanimações suaves.

- Ícones modernos.

- Tipografia forte e bem hierarquizada.

- Excelente experiência em dispositivos móveis.



Não utilizar azul, roxo, cores neon ou elementos visuais genéricos.



A identidade precisa parecer uma plataforma financeira profissional.

FAÇA PARTE DA BLACK PAY

Botão: CANDIDATAR-SE

CANDIDATURA — SÓCIO INVESTIDOR

Etapa 2: Informações pessoais.



Etapa 3: Perguntas específicas da modalidade escolhida.



Etapa 4: Revisão das informações.



Etapa 5: Confirmação de envio.



Adicionar:



- Barra de progresso.

- Botões de voltar e continuar.

- Validação dos campos.

- Máscara para WhatsApp.

- Campos obrigatórios identificados.

- Mensagens de erro claras.

- Animações suaves entre etapas.

- Layout responsivo.



Não perder os dados preenchidos quando o usuário voltar uma etapa.

8. BANCO DE DADOS E SEGURANÇA



Utilizar Supabase para armazenar as candidaturas.



Criar estrutura adequada para:



- Dados pessoais dos candidatos.

- Modalidade escolhida.

- Respostas específicas.

- Data de envio.

- Status.

- Observações administrativas.



Segurança obrigatória:



- Somente o administrador autenticado pode visualizar todas as candidaturas.

- Visitantes podem apenas enviar candidaturas.

- Nunca expor dados pessoais de candidatos publicamente.

- Configurar corretamente RLS.

- Não colocar chaves secretas no frontend.

- Validar dados também no backend.

- Proteger o painel administrativo.

- Registrar alterações de status e ações administrativas importantes.



Implementar consentimento de privacidade e informar a finalidade da coleta de dados, respeitando a LGPD.

---



10. REGRAS IMPORTANTES DE DESENVOLVIMENTO



- Não criar apenas uma landing page estática.

- Todos os formulários precisam funcionar.

- Salvar as candidaturas no banco de dados.

- O painel administrativo precisa funcionar de verdade.

- Não utilizar dados fictícios como se fossem candidatos reais.

- Não inventar números de faturamento ou quantidade de sellers.

- Não criar porcentagens de sociedade predefinidas.

- Não prometer rentabilidade.

- Não permitir que um candidato veja os dados de outro.

- Não alterar a estrutura financeira atual da Black Pay.

- Não criar funcionalidades de saque ou movimentação financeira nesse projeto.



Antes de implementar, analisar a estrutura existente do projeto e preservar funcionalidades que já estejam funcionando.



Entregar uma experiência visual premium, funcional e completa, tanto no celular quanto no computador.



O resultado precisa parecer um portal oficial de seleção de parceiros de uma empresa financeira profissional, e não um formulário comum.
